Arthur Barboza de Araújo Gois - 4°Período Sistemas de Informação

Para a criação do Registro e Acompanhamento de Solicitações de Manutenção foi utilizado a linguagem Python, onde as informações vão ficar em um banco de dados, onde a visualização do banco de dados está presente no Diagrama Entidade-Relacionamento.

O programa emula uma central de solicitações de manutenção, onde e possível criar, consultar, cancelar/excluir uma
solicitação(chamado).
